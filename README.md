# The Last Room

Невелика 3D-головоломка від першої особи: дослідіть кімнату, знайдіть підказки та відкрийте кодовий замок.

## Завантаження та запуск гри

**[Завантажити гру для Windows x64](https://github.com/Mark-Ovsiannikov/TheLastRoom/releases/latest/download/TheLastRoom-Windows-x64-v1.0.1.zip)**

1. Завантажте ZIP за посиланням вище або відкрийте [розділ Releases](https://github.com/Mark-Ovsiannikov/TheLastRoom/releases/latest).
2. Повністю розпакуйте архів за допомогою команди «Видобути все».
3. Відкрийте папку `TheLastRoom-Windows` і запустіть `TheLastRoom.exe`.

Не запускайте EXE безпосередньо з ZIP і не переносіть його окремо: папки `Engine` та `TheLastRoom` поруч із ним потрібні для роботи гри. Unreal Editor, Visual Studio та Python для запуску не потрібні.

Кнопка GitHub **Code → Download ZIP** завантажує вихідний проєкт. Готову гру завантажуйте за посиланням вище.

## Керування

| Клавіша | Дія |
|---|---|
| WASD | Переміщення |
| Миша | Огляд |
| Пробіл | Стрибок |
| E / ліва кнопка миші | Взаємодія |
| Цифри / цифровий блок | Введення коду |
| Enter | Підтвердження коду |
| Backspace | Видалити цифру |
| Esc / Tab | Закрити підказку або панель |
| R після перемоги | Почати заново |
| Alt + F4 | Закрити гру |

На стартовому екрані натисніть ліву кнопку миші. Цифри на панелі замка також можна натискати мишею. Інтерфейс гри — українською мовою.

## Вихідний проєкт

`TheLastRoom/TheLastRoom.uproject` відкривається в **Unreal Engine 5.8**. Карта: `/Game/Maps/LastRoom`.

Ігрова логіка міститься в Blueprints: `BP_FirstPerson`, `BP_RoomHUD`, `BP_ExitDoor`, `BP_RoomMode`. Плагін `RoomBuilder` — вимкнений інструмент створення графів у редакторі; для запуску готових Blueprint-ресурсів він не потрібен.

У версії **1.0.1** виправлено обробники WASD і руху миші. Перевірено події введення: переміщення в усіх чотирьох напрямках, огляд мишею, стрибок, E, Esc, цифри, Enter, відкривання дверей і R. Звіт: `TheLastRoom/QA-input-results.json`.

Проєкт — невеликий ігровий прототип із модульною геометрією та синтезованими звуками.
