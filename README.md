# The Last Room

Небольшая 3D-головоломка от первого лица: исследуйте комнату, найдите подсказки и откройте кодовый замок.

## Скачать и запустить игру

**[Скачать игру для Windows x64](https://github.com/Mark-Ovsiannikov/TheLastRoom/releases/latest/download/TheLastRoom-Windows-x64-v1.0.1.zip)**

1. Скачайте ZIP по ссылке выше или откройте [Releases](https://github.com/Mark-Ovsiannikov/TheLastRoom/releases/latest).
2. Распакуйте архив целиком через «Извлечь всё».
3. Откройте папку `TheLastRoom-Windows` и запустите `TheLastRoom.exe`.

Не запускайте EXE прямо внутри ZIP и не переносите его отдельно: папки `Engine` и `TheLastRoom` рядом с ним нужны для работы игры. Unreal Editor, Visual Studio и Python для запуска не требуются.

Кнопка GitHub **Code → Download ZIP** скачивает исходный проект. Готовую игру скачивайте по ссылке выше.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Перемещение |
| Мышь | Осмотр |
| Пробел | Прыжок |
| E / левая кнопка мыши | Взаимодействие |
| Цифры / цифровой блок | Ввод кода |
| Enter | Подтверждение кода |
| Backspace | Удалить цифру |
| Esc / Tab | Закрыть подсказку или панель |
| R после победы | Начать заново |
| Alt + F4 | Закрыть игру |

На стартовом экране нажмите левую кнопку мыши. Цифры на панели замка также можно нажимать мышью. Интерфейс игры — на украинском языке.

## Исходный проект

`TheLastRoom/TheLastRoom.uproject` открывается в **Unreal Engine 5.8**. Карта: `/Game/Maps/LastRoom`.

Игровая логика находится в Blueprints: `BP_FirstPerson`, `BP_RoomHUD`, `BP_ExitDoor`, `BP_RoomMode`. Плагин `RoomBuilder` — выключенный инструмент авторинга; для запуска готовых Blueprint-ассетов он не нужен.

В версии **1.0.1** исправлены обработчики WASD и движения мыши. Проверены события ввода: перемещение во всех четырёх направлениях, обзор мышью, прыжок, E, Esc, цифры, Enter, открытие двери и R. Отчёт: `TheLastRoom/QA-input-results.json`.

Проект представляет собой небольшой игровой прототип с модульной геометрией и синтезированными звуками.
