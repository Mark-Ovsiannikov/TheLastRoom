# The Last Room

Невелика гра від першої особи для Unreal Engine **5.8**. Одна кімната, три підказки, чотиризначний замок. Інтерфейс українською.

## Запуск

Готова Windows-гра з виправленим керуванням: запустіть **TheLastRoom.exe** у сусідній папці **WindowsBuild-Fixed**. Зберігайте цю папку цілком: виконуваний файл використовує файли з Engine і TheLastRoom поруч із ним. Unreal Editor для цієї збірки не потрібен. Попередня збірка у WindowsBuild має помилку обробників осей; використовуйте WindowsBuild-Fixed.

Для редагування відкрийте **TheLastRoom.uproject** у UE 5.8. Карта **Content/Maps/LastRoom** відкривається автоматично. Натисніть **Play → Standalone Game**. Рекомендована роздільна здатність: 1280 × 800 або більше.

## Керування

| Клавіша | Дія |
|---|---|
| WASD | Переміщення |
| Миша | Огляд |
| Пробіл | Стрибок |
| E / ліва кнопка миші | Взаємодія з об’єктом під прицілом |
| 0–9 / цифровий блок | Введення коду |
| Enter | Перевірка коду |
| Backspace | Видалення останньої цифри |
| C на екранній панелі | Очистити код |
| Esc / Tab | Закрити підказку або замок |
| R після перемоги | Перезапуск |

Цифрову панель можна повністю використовувати мишею. Під час читання та введення коду камера і пересування блокуються.

## Вміст проєкту

- **BP_FirstPerson** — рух, огляд, стрибок, трасування взаємодії до 240 см, читання підказок, введення й перевірка коду, перезапуск.
- **BP_ExitDoor** — металеві двері з плавною анімацією підйому.
- **BP_RoomHUD** — приціл, контекстна підказка, сторінки, клікабельна панель та повідомлення перемоги. Інтерфейс намальований стандартними Canvas-вузлами Blueprint.
- **BP_RoomMode** — ігровий режим і класи персонажа та HUD.
- **LastRoom.umap** — мебльована кімната й короткий коридор за дверима.
- **Materials** — матеріали дерева, штукатурки, фарби, сталі, латуні, паперу й книг.
- **Audio** — оригінальні синтезовані фоновий звук, кроки, папір, клавіші, помилка та відкривання дверей.

Геометрія модульна, побудована зі стандартних мешів Unreal Engine. Зовнішні платні набори й завантаження з Fab не потрібні. Весь ігровий код виконується через **Blueprints**, без Python чи C++ під час гри.

**RoomBuilder** — інструмент авторингу для створення графів у редакторі. Для гри він не потрібен. Його вихідні файли збережено для редагування генератора; плагін вимкнено у фінальному проєкті. Скрипт `Scripts/build_room.py` є вихідним генератором для порожнього проєкту, а готові `.uasset` та `.umap` вже лежать у Content. Не потрібно запускати генератор, щоб грати.

## Підказка до проходження — спойлер

Записка на столі вказує на годинник і книгу VIII. На годиннику — **08:25**. Книга пояснює формат: дві цифри годин, потім дві цифри хвилин, зі збереженням початкового нуля. Код — **0825**. Панель розташована ліворуч від металевих дверей. Неправильний код очищує введення та дозволяє повторити спробу. Правильний код піднімає двері та показує завершення гри.

## Редагування

Підказки, код і HUD знаходяться у графах Blueprints. Для зміни правильного коду змініть рядкову константу `0825` у гілці `Submit` в **BP_FirstPerson** і узгодьте з нею стрілки годинника. Інтерактивні актори позначені тегами `Note`, `Book`, `Clock` та `Panel`.

Для збірки Windows використайте **Platforms → Windows → Package Project**. Карта LastRoom вже додана в налаштування пакування.
